# Three Degrees of Financial Freedom: OSRS Money-Making Automation in 2025 with Python, ShareX, and Flipping Copilot

### Flipping Copilot

With the recent *Cambrian Explosion* of AI, Gielinor has witnessed the emergence of innovative money-making tools, some of which are accessible through the [RuneLite Plugin Hub](https://runelite.net/plugin-hub/). These plugins, vetted by the RuneLite team, provide a secure and non-malicious experience for players. Among these is Flipping Copilot, a plugin designed to act as an AI assistant for trading. Developed by [Cillian](https://runelite.net/plugin-hub/Cillian), also known as [cbrewitt](https://github.com/cbrewitt) on GitHub, Flipping Copilot offers intelligent suggestions for profitable item flips in the Grand Exchange, complete with session-based profit and loss tracking.


### Python

[Python](https://www.python.org/) serves as a robust alternative to AutoHotKey for creating color-based scripts, akin to [Sammichs' Scripts](https://sammichscripts.com/product/sammichs-premium-ahk-bot/), with the added advantage of leveraging powerful libraries for [random number generation](https://docs.python.org/3/library/random.html), [image processing](https://pillow.readthedocs.io/en/stable/), and [window management](https://pypi.org/project/pygetwindow/). Like AutoHotKey, Python enables the creation of scripts capable of interacting with the OSRS client to perform tasks such as clicking, typing, and reading text. Its versatility and advanced features make Python the ideal choice for this project.

### ShareX

[ShareX](https://getsharex.com/) is a free and open-source screenshot and screencast utility that offers a suite of tools for capturing and recording screen activity. Among its features is a built-in ruler tool, which proves invaluable for measuring the size and position of elements on the OSRS client. This capability ensures that scripts maintain universal compatibility across varying screen sizes and resolutions, making it an essential asset for this project.

## Requirements

A Flipping Copilot subscription is required for using this automation with member-items. As of the time of writing this article, the price is $6 per month. Additionally, Python 3.x and ShareX must be installed on your system to execute the scripts and capture bounding box coordinates accurately.
